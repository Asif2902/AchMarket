# Security Policy

## Supported versions

| Branch | Supported |
|--------|-----------|
| `hoster` | Yes |
| `main` / experimental | Best effort |

## Reporting a vulnerability

**Do not** file a public issue for security bugs.

Use GitHub **Security → Report a vulnerability** when available, or contact AchSwap maintainers privately.

Include impact, reproduction steps, and affected components (frontend / backend / contracts).

We aim to acknowledge reports within **7 days**.

## Notes

- Never commit private keys, Mongo URIs with passwords, or R2 credentials
- This project is experimental; treat production funds with caution
